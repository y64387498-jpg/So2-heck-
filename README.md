# Standoff 2 Oyun Yardımcısı

Bu proje hile değildir. Oyunun belleğine, dosyalarına, ağ trafiğine veya oynanışına müdahale etmez; anti-cheat atlatmaz ve ban koruması sağlamaz.

## Özellikler
- Tek bir BAŞLAT butonuyla 2 dakikalık sayaç.
- Android'in diğer uygulamaların üzerinde gösterme iznini isteyen ayar düğmesi.
- İzin verildiyse ekranda küçük, zararsız geri sayım penceresi.
- Süre bitince Standoff 2 uygulamasını açmayı dener.

## GitHub'a yükleme
1. ZIP'i telefona indir ve çıkart.
2. GitHub'da yeni bir repository oluştur.
3. Çıkartılan klasörün içeriğini repository'ye yükle.
4. APK üretmek için Android Studio'da projeyi açıp Build > Build APK(s) seç.

## Not
Android Studio/Gradle ile derleme gerekir. GitHub'a kaynak kod yüklemek tek başına telefona APK kurmaz. Bazı Android sürümleri arka plan servislerini kısıtlayabilir.
